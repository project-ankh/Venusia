# Venusia

An occult services website for Venusia: tarot and love readings, pendulum sessions, spells, and custom oils, incense and herbal blends. Gold and white theme with animated Venus, tarot card and healing-energy effects.

## Files
- `index.html` — page structure and text
- `style.css` — all styling and animations
- `script.js` — spell price list and click sparkles

## Run locally
Keep all three files in one folder and open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new repository and upload all four files.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit
